# Mappa moduli implementata

```text
App/          bootstrap e stato UI
Core/         settings e protocollo
Models/       registry, download e model store
Network/      discovery, WSS e service lifecycle
Pipelines/    testo, media e DSP
Runtime/      llama.cpp e mtmd
Security/     identita e pairing
Storage/      budget, journal e cleanup
Tasks/        coordinator e attivita
Views/        onboarding, dashboard, modelli, attivita, storage, settings
```

```text
studio/backend/core/companion/    manager, modelli e sicurezza
studio/backend/routes/            API Companion
studio/frontend/src/features/settings/  API e sezione iPhone Companion
```

Questa mappa descrive i percorsi reali; non è una struttura alternativa da creare.
